EJERCICIO 12 

Número de Bacon

Lenguaje natural:
Se hace una búsqueda en amplitud empezando en Kevin_Bacon, que está en el nivel 0. Los compañeros de
película de un actor del nivel n quedan en el nivel n + 1. El nivel en que se encuentra a un actor es su
número de Bacon. Se guarda el nivel de cada actor en un diccionario, que también sirve para no visitar dos
veces al mismo actor. Si la cola se vacía sin encontrar al actor, no hay ninguna cadena de películas hasta
Kevin_Bacon y se devuelve -1.

Precondiciones:
- El grafo no es nulo y contiene el vértice "Kevin_Bacon".
- El actor no es nulo.

Postcondiciones:
- El grafo no cambia.
- Devuelve 0 para Kevin_Bacon, el largo mínimo de la cadena de películas para un actor conectado, y
  -1 si el actor no está en el grafo o no tiene ninguna cadena hasta Kevin_Bacon.

Pseudocódigo:

numBacon(grafo, actor) devuelve entero
Comienzo
    SI grafo ES NULO OR actor ES NULO ENTONCES
        error "el grafo y el actor no pueden ser nulos"
    FIN SI
    SI NO existeVertice(grafo, "Kevin_Bacon") ENTONCES
        error "el grafo no contiene a Kevin_Bacon"
    FIN SI
    SI NO existeVertice(grafo, actor) ENTONCES
        devolver -1
    FIN SI

    nivel <- diccionario vacío             // actor -> número de Bacon (también marca los visitados)
    cola <- cola vacía
    nivel["Kevin_Bacon"] <- 0
    cola.encolar("Kevin_Bacon")

    MIENTRAS cola NO ESTA VACIA HACER
        actual <- cola.desencolar()
        SI actual = actor ENTONCES
            devolver nivel[actual]
        FIN SI
        PARA CADA pelicula EN adyacencias(grafo, actual) HACER
            companiero <- pelicula.destino
            SI companiero NO ESTA EN nivel ENTONCES
                nivel[companiero] <- nivel[actual] + 1
                cola.encolar(companiero)
            FIN SI
        FIN PARA
    FIN MIENTRAS
    devolver -1
Fin

CASOS DE PRUEBA

Cada caso indica la entrada y lo que se espera.

 1. Kevin_Bacon: su número de Bacon es 0.
 2. Ejemplo del enunciado: Tom_Hanks trabajó con Kevin_Bacon (Apolo_13) y Sally_Field con Tom_Hanks
    (Forrest_Gump): Tom_Hanks tiene 1 y Sally_Field tiene 2.
 3. Cadena larga Kevin_Bacon - A - B - C - D: D tiene 4.
 4. Dos cadenas hacia D, Kevin_Bacon - A - D (2 películas) y Kevin_Bacon - B - C - D (3 películas): D tiene 2,
    la más corta.
 5. Ciclo entre actores (A, B y C) con A unido a Kevin_Bacon: C tiene 2 y la búsqueda termina.
 6. Actor sin ninguna cadena de películas hasta Kevin_Bacon: se devuelve -1.
 7. Actor que no está en el grafo: se devuelve -1.
 8. Grafo sin Kevin_Bacon: error.
 9. Grafo o actor nulo: error.
10. El grafo no cambia después de consultar: tiene los mismos vértices y aristas.
11. Carga de archivos válidos con una línea vacía al final: la cantidad de actores y de relaciones es la correcta.
12. Carga con un encabezado en la primera línea y con punto y coma como separador: el encabezado se ignora.
13. Carga con una relación que nombra un actor desconocido o que tiene columnas de menos: se descarta y se
    cuenta como descartada.
14. Archivos del ejercicio: 61 actores, 81 aristas y 2 relaciones descartadas. Los números de Bacon son los de
    la sección RESULTADOS.
